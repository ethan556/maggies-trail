## D. Content fixes required beyond simple re-pinning

These are the only lesson-content edits made in this packet. Each was a genuine defect introduced
by this session's own edit batch (not something a test re-pin can honestly paper over — see the
per-item reasoning), and each is either a wording-only change, an established sibling-pattern
completion, or a single-word case fix. Answers, hints, `conceptTag`, evaluator logic, and IDs were
never touched.

1. **`content/courses/decimal-fluency-g5/lessons/g5d-01-01.json` — removed the stale `variant`
   key from `k3`.** `k3`'s prompt was rewritten to decimal prose ("Add 0.65 and 0.19. What is the
   sum?") but kept the `g2-place-value-1000/Pv1000AddTradeNumeric` variant binding — a generator
   that only ever emits whole-number `"a + b = ?"` prompts and cannot parse this shape (confirmed:
   `solvePrompt` returns `undefined` on it). The four sibling steps in the same S316 batch
   (`g5d-01-03/k2`,`/ch1`, `g5d-01-05/k2`, `g5d-02-02/k2`, `g5d-03-03/k2`,`/ch1`) had this exact
   stale-variant defect removed already, per `S316_LANEA_MIXED_REVISION_IMPLEMENTATION.md`; this
   file's `k3` was the one instance the batch missed. Removed only the `"variant"` key; prompt,
   answer, `commonErrors`, feedback untouched.
2. **`content/courses/decimal-fluency-g5/lessons/g5d-01-03.json` — reworded `ch1`'s prompt
   wording only.** `k2` ("Add 3.5 and 4.65. Pad 3.5 as 3.50 first, so the columns line up. What is
   the sum?") and `ch1` ("Add 6.8 and 2.57. Pad 6.8 as 6.80 first, so the columns line up. What is
   the sum?") shared one phrasing template that normalizes identically once digits are stripped —
   a live same-sitting repetition, caught by session248's own detector test. Reworded `ch1` to
   "Find the sum of 6.8 and 2.57 in columns. Since 6.8 equals 6.80, line up the decimal points
   before adding." Same numbers, same answer (9.37), same `commonErrors`/feedback — wording only.
3. **`content/courses/decimal-fluency-g5/lessons/g5d-01-05.json` — rebalanced `k3`'s mcq option
   label lengths.** The new flip-vs-trade mcq (converted from numeric this session) had option
   labels spanning 35–101 characters (66-char spread against the gate's 14-char cap) — the correct
   option's label was visibly the longest, an answer-length cue. Reworded all four labels to a
   uniform ~56–68 character range, preserving each option's exact claim and its (untouched)
   feedback.
4. **`content/courses/geometry-g7/lessons/g7-04-01.json`** — lowercased one ALL-CAPS emphasis word
   ("it CAN form a triangle" → "it can form a triangle") in a `commonErrors` feedback string;
   sentence-case gate, meaning unchanged.
5. **`content/courses/geometry-g7/lessons/g7-04-03.json`** — same fix, one word ("cut PARALLEL to
   the base" → "cut parallel to the base") in the `i2` mcq's wrong-option feedback.
